# LeetCode 数学考察问题

在 LeetCode 上，涉及数学考察的题目涵盖了多个领域，以下是常见的分类：

## 1. 数论（Number Theory）
- 主要考察质数筛选（如埃氏筛法）、最大公约数和最小公倍数、模运算、整除问题等。
- 示例题目：
    - 204. 计数质数 (Count Primes)
    - 172. 阶乘后的零 (Factorial Trailing Zeroes)
    - 365. 水壶问题 (Water and Jug Problem)

## 2. 组合数学与概率（Combinatorics and Probability）
- 涉及排列、组合、二项式系数计算、概率事件的求解。
- 示例题目：
    - 62. 不同路径 (Unique Paths)
    - 2318. 统计合法路径的数目 (Count the Number of Valid Paths)
    - 384. 打乱数组 (Shuffle an Array) —— 涉及概率的随机打乱算法。

## 3. 代数与线性方程（Algebra and Linear Equations）
- 需要解一元或多元方程组，有时结合动态规划或贪心算法。
- 示例题目：
    - 640. 求解方程 (Solve the Equation)
    - 1359. 有效排列的数量 (Count All Valid Pickup and Delivery Options)

## 4. 几何与坐标系（Geometry and Coordinate Systems）
- 主要考察2D/3D几何计算，如求距离、中点、面积，以及坐标旋转与变换。
- 示例题目：
    - 593. 有效的正方形 (Valid Square)
    - 223. 矩形面积 (Rectangle Area)
    - 149. 直线上最多的点数 (Max Points on a Line)

## 5. 数学优化（Mathematical Optimization）
- 涉及最优解求法，如求最大/最小值，结合动态规划、贪心算法解决数学模型。
- 示例题目：
    - 213. 打家劫舍 II (House Robber II)
    - 343. 整数拆分 (Integer Break)

## 6. 矩阵与线性代数（Matrix and Linear Algebra）
- 包含矩阵操作、求解矩阵的行列式或逆矩阵，以及与图算法结合。
- 示例题目：
    - 73. 矩阵置零 (Set Matrix Zeroes)
    - 54. 螺旋矩阵 (Spiral Matrix)
    - 378. 有序矩阵中第 K 小的元素 (Kth Smallest Element in a Sorted Matrix)

## 7. 模拟与数学模型（Simulation and Modeling）
- 一些题目考察如何将数学模型用代码表示，并进行模拟运算。
- 示例题目：
    - 396. 旋转函数 (Rotate Function)
    - 233. 数字 1 的个数 (Number of Digit One)


# 常见算法技巧

## 1. 前缀和（Prefix Sum）
前缀和是一种用于快速计算数组中某一段连续元素和的技巧。通过构造一个前缀和数组，可以在常数时间内获取任意区间的和。  
常见应用包括求区间和、频繁查询的累加和等。


## 2. 差分（Difference Array）
差分数组是一种用于高效处理区间更新的技术。通过维护一个差分数组，可以在 O(1) 时间内对数组的某个区间进行加减操作。  
适用于处理范围更新问题，尤其是需要在多个操作后快速获取最终数组的情况。

## 3. 逆元（Modular Inverse）
逆元在数论中被广泛应用，尤其是在模运算中。通过逆元，可以在求解方程或进行组合数学时处理分母的问题。  
在计算组合数时，使用逆元可以有效避免大数溢出问题。

## 4. 滚动哈希（Rolling Hash）
滚动哈希是一种用于字符串匹配的技术，能够在常数时间内更新哈希值。它常用于处理子串的比较和查找问题。  
滚动哈希在解决最长重复子串、字符串匹配等问题中表现良好。



# 区间更新相关数据结构

## 1. 线段树（Segment Tree）
线段树是一种基于树的数据结构，用于存储区间信息，可以在 O(log n) 时间内进行区间更新和查询。  
线段树适用于处理更复杂的区间查询，如求和、最小值、最大值等。线段树的实现相对复杂，但它提供了强大的功能，能够支持动态更新和查询。

## 2. 树状数组（Fenwick Tree）
树状数组是一种高效的数据结构，可以用于维护前缀和，并支持在 O(log n) 时间内进行单点更新和区间查询。  
虽然它主要用于前缀和计算，但也可以通过一定的变换来支持区间更新。

## 3. 懒惰传播（Lazy Propagation）
懒惰传播是一种与线段树结合使用的技术，旨在优化区间更新。  
通过将更新延迟到实际查询时，可以减少不必要的操作，使得区间更新更高效。懒惰传播允许我们在 O(log n) 时间内更新区间，而不必立即更新所有相关的叶子节点。

## 4. 排序与离散化（Sorting and Discretization）
在某些情况下，可以通过对数组进行排序和离散化来优化区间更新。  
这种方法通常涉及将更新映射到一组离散值，从而降低时间复杂度。

## 5. 平衡树（如 AVL 树、红黑树）
平衡树可以用于维护动态集合，支持快速的插入、删除和查询操作。  
在区间更新问题中，通常通过在节点中存储额外的信息来实现高效的区间查询。
